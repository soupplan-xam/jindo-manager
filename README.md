# 진도계획표

시간표와 학사일정으로 반별 수업 차시를 자동 계산하는 교사용 진도 관리 도구. 데스크톱·모바일 반응형.

차시 번호는 저장하지 않습니다. 시간표·일정·결손 기록에서 매번 파생 계산하므로, 하루를 결손 처리하면 뒤의 모든 차시가 저절로 밀리고 되돌리기도 즉시 반영됩니다.

## 기능

- **통합 화면** — 상단 대시보드 카드 3개(오늘의 수업 · 반별 진도 · 고사 D-day) 아래에 왼쪽 진도표, 오른쪽 차시별 내용이 나란히 놓입니다. 둘 다 접을 수 있고, 가운데 조절 바를 드래그하면 진도표는 표 크기가 함께 줄어들고(가로 스크롤 없음) 넘치는 차시별 내용은 패널 안에서 세로로 스크롤됩니다.
- **진도표** — 주간 시간표 위에 반별 차시 번호가 자동으로 표시됩니다. 칸을 누르면 결손 처리 · 수행평가 · 내용 편집을 할 수 있습니다. 결손과 수행평가 모두 차시를 소모하지 않아 이후 차시가 자동으로 밀리며, 수행평가는 빨간 글씨로 구분해 표시됩니다.
- **보강 · 교환 · 결손 사유** — 빈 칸을 누르면 [교환](진도 셈)이나 [보강](진도 안 셈)을 고릅니다. 교환은 반을 골라 넣고 차시 옆에 「교환」으로 표시됩니다. 보강은 반이 아니라 장소(예: 과학실)를 적고, 회색 칸으로 고정되며 반 목록·반 색·진도에 들어가지 않습니다. 원래 칸은 [교환으로 비우기]로 비우면 「교환으로 빠짐」이 남습니다. 결손 처리 때 사유(출장·연수 등)를 바로 넣고, 나중에 [결손 사유 고치기]로 바꿀 수 있습니다.
- **칸 메모** — 칸 메뉴의 [메모]로 그 날 그 반 칸에만 짧은 메모(예: 3, 15번 결시)를 남깁니다. 차시별 내용과 달리 다른 반·같은 차시로 퍼지지 않고, 수행평가·결손·보강 칸에도 쓸 수 있습니다. 칸 아래에 ✎로 보이고 인쇄에도 나옵니다.
- **담임 · 출결 안내 메시지** — 상단 [담임]에서 날짜·학생 이름·사유(질병·인정·기타)·출결(지각·조퇴·결석·결과)·서류 안내를 고르면 학부모 안내 메시지가 완성되고, [메시지 복사]로 e알리미 등에 붙여 넣어 보냅니다. 학교·반·담임 이름과 문구 틀은 고쳐서 저장할 수 있고, 학생 이름·사유는 저장하지 않습니다. 앱이 메시지를 직접 보내지는 않습니다.
- **달력** — 상단 [달력]에서 월간 달력에 학사일정·공휴일·24절기와 날짜별 할 일을 함께 봅니다. 날짜를 누르면 할 일을 적고 체크하며, [칠하기]로 시작일부터 끝날까지 끌어 기간을 색칠합니다. 공휴일은 2026~2027학년도 표(참고용), 절기는 태양 황경으로 계산합니다.
- **앱으로 설치** — 크롬·엣지에서 설치하면 바탕화면·작업표시줄 아이콘으로 따로 창이 열립니다(설정 > 앱으로 설치). 휴대폰은 [홈 화면에 추가].
- **현재 교시 · 급식 · 날씨** — 설정 > 교시 시각을 넣으면 대시보드 「오늘」에 지금 교시·남은 시간이 나옵니다. 설정 > 우리 학교에서 학교를 고르면 「급식 · 날씨」 카드에 나이스 급식(알레르기·칼로리)과 날씨·미세먼지(Open-Meteo, 환경부 등급)가 나옵니다.
- **바탕화면 위젯(윈도우)** — `desktop/` 의 Electron 프로그램이 배포된 화면의 `#widget`을 테두리 없는 작은 창으로 띄웁니다. 알림 영역 메뉴로 숨기기·항상 위·자동 실행. `desktop-v*` 태그를 올리면 GitHub Actions가 설치 파일(.exe)을 릴리스에 올립니다.
- **초근(초과근무)** — 상단 [초근]. 방과후 계획서(HWPX·PDF)를 올리면 강좌명·기간·요일·시간을 찾아 채우고(확인 후 저장), 그 날들은 방과후 끝나는 시각으로 초과근무를 자동 계산합니다. 야근·휴일 근무는 직접 기록. 기본 기준: 퇴근 16:40, 평일 1시간 공제, 하루 최대 4시간, 월 합계 시간 미만 버림(계산 기준에서 변경). 월별 CSV 내보내기.
- **반 색** — 칸 메뉴의 [반 색 바꾸기]나 시간표 수정의 반 칩에서 파랑 3 · 노랑 3 중 고릅니다. [다른 색 더 보기]로 30색도 쓸 수 있습니다.
- **차시별 내용** — 과목 탭별로 차시마다 수업 내용을 적습니다. 여기 적은 내용이 진도표의 같은 차시 칸에 자동으로 표시되고, 칸에서 고치면 같은 과목·차시의 모든 칸에 반영됩니다 (양방향 연동). 반마다 과목을 지정할 수 있어 같은 과목 반들은 내용을 공유합니다.
- **시간표 등록 2가지** — ① 칸들을 탭해 선택한 뒤 [반 등록]으로 한 번에 배정 (색 자동 부여), ② 팔레트에서 반을 고른 뒤 드래그로 칠하기. 반 색은 팔레트의 색 사각형을 눌러 12색 중에서 바꿀 수 있습니다.
- **온보딩** — 학기 기간 · 시간표 · 일정 등록을 한 화면에서 끝내며, intro.js 안내 투어가 처음 한 번 자동으로 나옵니다. 진도표 화면 우상단의 되돌아가기 아이콘으로 언제든 이 화면에 다시 옵니다.
- **해밀고 마크** — 최초 설정 화면 우상단의 해밀 배지를 누르고 교사 이름을 검색하면 미리 등록된 데이터로 바로 시작합니다. 데이터는 `public/teachers.json`에 넣습니다 (형식은 아래).
- **일정** — 휴업일·행사·고사·개인(출장) 일정을 관리합니다. 날짜 선택기로 넣고, 고사처럼 여러 날인 일정은 "기간"을 켜면 시작·종료일을 받습니다(고사는 자동으로 켜집니다). 어느 필드에서든 엔터로 등록되고, 모든 유형이 해당 수업을 자동 결손 처리합니다. 교시·반 단위 부분 결손도 지원합니다.
- **구간별 차시 내용** — 고사 뒤 1차시부터 다시 세면 「1차 정기시험 전 / 후 / 2차 정기시험 후」처럼 구간이 나뉘고, 차시별 내용도 구간마다 따로 적습니다. 차시별 내용 패널 위 구간 버튼으로 바꾸며, 보고 있는 주의 구간이 자동으로 골라집니다. 새 구간이 비어 있으면 앞 구간 내용을 복사해 올 수 있습니다. 설정의 「차시 초기화 기준 고사」에서 「모든 고사 후마다」를 고르면 고사마다 1차시부터 다시 셉니다.
- **고사 후 차시 리셋 · 진도 목표 고사** — 「차시 초기화 기준 고사」 이후 차시를 1부터 다시 셉니다. 대시보드의 반별 진도(현재/총 차시 · 남은 차시)는 따로 고르는 「진도 목표 고사」까지 셉니다. 예: 1차 정기시험 뒤 1차시부터 다시 세고, 진도는 2차 정기시험까지. 목표를 비워 두면 초기화 이후 다음 고사, 「학기 말까지」도 고를 수 있습니다.
- **날짜 입력** — 학기 기간과 일정 날짜는 `10.12`, `1012`, `2026-10-12`, `10월 12일`처럼 한 번에 칩니다. 연도를 빼면 학기에 가까운 해로 잡습니다(2학기에 `1.8`은 이듬해 1월). [기간] 달력에서 시작일·종료일을 차례로 누르거나, 칸에서 ↑↓로 하루씩 옮길 수 있습니다. 일정 시작일을 옮기면 기간 길이를 유지한 채 종료일이 따라옵니다.
- **설정 모달** — 우상단 톱니 아이콘. 학기 설정, 차시 카운팅, 인쇄(범위·크기), 데이터(JSON/CSV, 전체 초기화), 파일 인식(API 키).
- **학사일정 검색** — 일정 화면의 [학교검색]에서 우리 학교 이름을 찾으면 나이스 오픈API로 그 학교의 학년도 전체 학사일정을 실시간 조회해 그대로 가져옵니다. 학년별로 걸러 볼 수 있습니다. 넣은 일정은 그 날 수업을 결손 처리하므로 휴업일·고사(지필평가)만 미리 골라 두고, 수업이 실제로 빠지는 행사는 직접 고르면 됩니다. 유형 배지를 눌러 행사·휴업일·고사로 바꿀 수 있고, 이어지는 날은 한 건(기간)으로 묶여 들어갑니다. 이미 넣어 둔 일정은 "이미 등록됨"으로 표시되어 중복되지 않습니다.
- **파일에서 가져오기** — 시간표·학사일정을 엑셀/CSV/PDF/이미지로 올리면 AI가 초안을 만들고, 원본과 나란히 놓고 검토한 뒤 적용합니다. OpenRouter API 키를 본인이 등록해 브라우저에서 직접 호출하는 방식(BYOK)이라 별도 서버가 없습니다.
- **인쇄** — [인쇄] 버튼에서 범위(이번 주 · 2주치)와 크기(작게·중간·크게)를 고릅니다. 2주치는 보고 있는 주와 그 다음 주를 이어서 **한 장에** 뽑습니다 — 한 주만으로 A4 한 장을 쓰는 「크게」는 두 장이 되므로 2주치에서는 목록에서 빠집니다. 고른 기준은 다음 인쇄에도 이어지며(설정 > 인쇄에서도 바꿀 수 있습니다), 화면을 그대로 찍지 않고 종이에 맞춰 따로 조판합니다.
- **JSON 저장·불러오기 / CSV 내보내기 / 초기화** — 설정 > 데이터에서 전체 백업·복원과 CSV 내보내기. 저장 파일에 API 키는 담기지 않습니다. 전체 내용 초기화는 확인 모달을 거쳐 진행됩니다.

모든 데이터는 브라우저 localStorage에만 저장됩니다.

## 시작하기

```bash
npm install
npm run dev
```

검사: `npm run check` (차시·목표 고사 계산, 날짜 해석), `npm run build`

첫 실행 시 온보딩 한 화면(학기 기간 + 시간표)을 채우면 바로 진도표가 생성됩니다.

## 해밀고 교사 데이터 형식

`public/teachers.json`:

```json
{
  "teachers": [
    { "name": "홍길동", "data": { "semStart": "2026-08-17", "semEnd": "2027-01-09", "classes": ["2-1"], "pattern": { "1-2": "2-1" }, "events": [] } }
  ]
}
```

`data`는 설정 > 데이터의 JSON 내보내기에 담기는 `data`와 같은 형식입니다. 앱에서 직접 시간표를 만든 뒤 내보낸 파일의 `data`를 그대로 붙여넣는 것이 가장 쉽습니다.

## 학사일정 데이터

학사일정 검색은 [나이스 오픈API](https://open.neis.go.kr)를 브라우저에서 직접 호출합니다(서버 없음). 학교 검색은 `schoolInfo`, 일정은 `SchoolSchedule`을 학년도 전체(3.1~이듬해 2월 말) 범위로 조회하므로 따로 갱신할 데이터가 없습니다. 인증키는 `src/schools.js`의 `NEIS_KEY` 상수입니다 — 학사일정은 공개 데이터라 키가 드러나도 조회량 제한 밖의 위험은 없고, 키를 바꾸려면 그 값만 고치면 됩니다.

자료는 나이스 하나만 씁니다. 예전에는 나이스가 실패하면 미리 만들어 둔 3월분 데이터로 조용히 넘어갔는데, 그러면 화면에는 3월 일정만 나오면서도 오류처럼 보이지 않아 무엇이 잘못됐는지 알 수 없었습니다. 지금은 실패하면 사유를 그대로 보여주고 [다시 시도]를 띄웁니다.

## 파일 인식 설정 (선택)

파일 인식은 편의 기능입니다. 키가 없어도 앱의 나머지 기능은 모두 동작합니다.

1. [openrouter.ai/keys](https://openrouter.ai/keys)에서 API 키를 발급받습니다.
2. 설정 > 파일 인식에 키를 붙여넣고 "연결 확인"을 누릅니다.
3. 기본 모델은 `google/gemini-2.5-flash`이며 변경할 수 있습니다. 이미지·PDF 인식에는 비전 지원 모델이 필요합니다.

키는 브라우저 localStorage에만 저장되며 파일 인식 요청에만 사용됩니다.

## 기술 스택

- React + Vite (클라이언트 전용, 서버 없음)
- intro.js (온보딩 안내 투어)
- SheetJS (엑셀/CSV 파싱), pdf.js (PDF 텍스트 추출·렌더링)
- OpenRouter API (파일 인식, BYOK)
- 나이스 오픈API (학사일정 검색)
